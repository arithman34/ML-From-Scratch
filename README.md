# ML-From-Scratch

Machine Learning Algorithms and Deep Learning implemented from scratch using only NumPy (no high-level libraries like Sklearn, TensorFlow, or PyTorch).

# 📖 Overview

This repository aims to implement traditional machine learning algorithms and deep learning models from scratch using only NumPy. The focus is on understanding the fundamental concepts and the mathematics behind the algorithms, rather than relying on high-level libraries like Sklearn, TensorFlow, or PyTorch. This project is ideal for educational purposes, allowing users to learn how machine learning algorithms work under the hood.

# 🚀 Features

- **Autograd Tensors**: An automatic differentiation engine to compute gradients.
- **Modular Design**: Components are designed to be reusable and extendable.
- **No Dependencies**: Pure NumPy, no high-level libraries.
- **Educational Focus**: Each component is designed to be clear and understandable, with detailed comments and explanations.

# 📚 Documentation

# 🧪 Usage Examples

Train a simple MLP on synthetic data:

```bash
python examples/train_binary_classifier.py
```

Train a CNN on MNIST dataset:

```bash
python examples/train_digit_classifier.py
```

# 🎓 Educational Goals

- **Transparency**: Avoid black box behavior—learn by looking under the hood.
- **Flexibility**: Modify and extend components to suit your needs.
- **Understanding**: See inside activations, gradients, weight updates.
- **Consistency**: Algorithms are implemented using OOPs, with methods similar to established libraries.
